# QFA source/native spatial fields

This endpoint lifts the accepted coordinate bridge to actual spatial vector fields. It supplies pointwise inverse laws, source and native `L²` classes in both directions, almost-everywhere representative identities, and exact pointwise physical Euclidean-norm transport.

It does not prove source solenoidality, CKN `IsInJ`, an ESS good-time contract, any PDE construction, or either QFA root.
