# Compact-carrier Schwartz admission

Four full-type audited theorems establish the preterminal unique-differentiation
domain, vanishing of all within-derivatives outside a closed spatial carrier,
vanishing of the corresponding weighted jets, and uniform weighted derivative
bounds on each compact regular time slab for a jointly smooth field with one
fixed compact spatial carrier.

The result supplies the abstract R3-02 admission lemma, including time zero.
It does not import a concrete singular seed and does not require a bound uniform
up to the terminal singular time.
