# Whole-space FDSN contracts

This package fixes the actual Euclidean NSE operators, local Schwartz seed,
compact positive-time rapidly decaying force, compact-local terminal blowup,
continuous Fourier and helical observables, and the five-clause common-witness
family target. Every definition has an independent literal consumer; each
structure is checked against its complete conjunction of fields.

Six elementary theorems cover real/complex conversion, positivity, initial
divergence freedom, tail agreement, and extraction of a nonzero late slice.
This package does not supply a family witness or prove the canonical R3 root.
