# FDSNR3HelicalFrame

The intrinsic helical projector is identified with the scalar coefficient
projector in any ordinary orthonormal frame of the two actual curl
eigenvectors and the normalized longitudinal vector. Consequently, its
squared norm and the actual Fourier helical power equal the squared
magnitude of the corresponding scalar coefficient.
