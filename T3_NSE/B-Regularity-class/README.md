# B regularity classes on T³

The two programs retain distinct hypotheses and time ranges:

| Program | Accepted scope |
|---|---|
| [WFB](WFB/README.md) | The explicit finite Fourier budget gives global smooth continuation from smooth initial data. |
| [QFB](QFB/README.md) | The original Leray–Hopf theorem supplies smooth tails, energy equality and uniqueness from post-cutoff traces. |

WFB also contains the finite-cap R0 admission material used in its development.
R0 denotes that admission result; its domain is the periodic torus.
