1. TARGET AND PRECISE CLOSURE BOUNDARY

The selected goal is the conditional implication

  EHRENFEST_OBSTRUCTION:
    forall nu : Real, 0 < nu ->
      StoppedCommutatorBound nu -> Not (NSE_B nu).

The stopped condition remains an explicit hypothesis. Proving that an actual
smooth datum satisfies it is a separate, unresolved existential problem.
Acceptance of this implication therefore does not establish an unconditional
Navier--Stokes counterexample.

Weak_Fourierman_B is retained as an accepted foundation/reference in the
current project organization. Its finite Fourier-budget hypothesis and existing
evidence remain intact. Neither WFB nor its finite-budget hypothesis is an
additional premise of the displayed obstruction theorem.

The mathematical proof uses the actual canonical Fourier--Galerkin family.
The complete Hilbert-space Heisenberg interpretation is a separately tracked
stronger construction. Its self-adjointness, domain and unitary-flow results
are not premises of this scalar root. The name StoppedCommutatorBound retains
its literal coefficient definition until that interpretation is also proved.

The current scalar-root proof and its exact external acceptance are recorded
below. The earlier complete mathematical program and implementation history
are retained in audits/goal-transition-22431f/EHRENFEST_OBSTRUCTION_B_TIER.txt.

2. EXACT DATA, DEFINITIONS AND EXPLICIT PREMISES

Spatial setting: the unit-volume periodic three-torus; unforced NSE; nu > 0.
A := -Delta. Leray projection is denoted L. P_N is the existing orthogonal
Fourier cutoff, commuting with derivatives and L. Put Pi_N := P_N L.
The logical index n : Nat always denotes physical cutoff N := n+1 > 0.

SmoothDatum := {a : Field // SmoothSigmaZero a}.
Here SmoothSigmaZero means the actual real, smooth, periodic, divergence-free,
mean-zero physical datum. The same a and nu are used at every cutoff.

u_n := canonicalGalerkinSolution nu hnu a.val a.property (n+1).
Its physical field and coefficient realization are related by the existing
finite Fourier synthesis and Parseval identities. For the trajectory define

  e_n(t) := coefficientDissipation(N, u_n.coeff(t))/2
          = ||grad u_n(t)||_2^2/2,
  Z_n(t) := coefficientLaplacianSquare(N, u_n.coeff(t)),
  Pwr_n(t) := coefficientEnstrophyNonlinearPower(N, u_n.coeff(t)).

Pwr is the native nonlinear-power symbol, not pressure or a projection.
The actual coefficient identity is

  (2 e_n)' = -2 nu Z_n - 2 Pwr_n,
  e_n' = -nu Z_n - Pwr_n.

For eStar > 0 put

  V_n(t) := (1 + e_n(t)/eStar)^(-1),
  c_n(t) := (nu Z_n(t) + Pwr_n(t)) /
             [eStar (1 + e_n(t)/eStar)^2].

The literal no-hit guard is

  PreHit(e,R,T,t) :=
    0 <= t AND t < T AND
    forall s, 0 <= s -> s <= t -> e(s) < R.

StoppedForDatum(nu,hnu,a,eStar,gamma,R) means

  eStar > 0; gamma > 0; R_n > 0 for every n; R_n -> +infinity;
  exists n0, forall n >= n0, forall t,
    PreHit(e_n,R_n,1/gamma,t) -> c_n(t) <= -gamma.

StoppedCommutatorBound(nu) :=
  exists hnu : 0 < nu, exists a : SmoothDatum,
  exists eStar gamma : Real, exists R : Nat -> Real,
    StoppedForDatum(nu,hnu,a,eStar,gamma,R).

NSE_B(nu) :=
  forall a : Field, SmoothSigmaZero a ->
    exists U : Velocity, exists P : Pressure,
      GlobalSmoothNSE nu a U P.

No datum, eStar or gamma may depend on n. No uniform Galerkin estimate,
singularity conclusion, or operator certificate is hidden inside the stopped
predicate. It is a defined Prop, not a global Lean axiom declaration.

INT02 -- RECIPROCAL CALCULUS

Nonnegativity of coefficientDissipation gives e_n(t) >= 0 for t >= 0.
Since eStar > 0,

  0 < V_n(t) <= 1.

Differentiate the native enstrophy identity through the real reciprocal:

  V_n' = -e_n' / [eStar (1 + e_n/eStar)^2]
       = (nu Z_n + Pwr_n) / [eStar (1 + e_n/eStar)^2]
       = c_n.

For t>0 this is an ordinary HasDerivAt statement. At the initial endpoint
one may use the within-Ici derivative; the final comparison only requires
ordinary derivatives on the open interval. The canonical reciprocal is
continuous on every closed nonnegative time slab.

SIGN CHECK: for an exact caloric shear, Pwr_n=0, so c_n>=0. Such a trajectory
cannot provide the negative-rate witness. Changing this sign would change
the premise and invalidate the chain.

INT04 -- REFERENCE BOUNDS AND PHYSICAL TAIL

For N=n+1 define

  v_n := P_N U,
  r_n := U-v_n,
  w_n := u_n-v_n.

Smoothness of U on the strict compact slab supplies Sobolev and spatial
derivative bounds. Finite Fourier l1 control, applied to the coefficients
and first-derivative coefficients, yields a number M>=1, independent of n,
such that for t in [0,T], x in the fundamental cube,

  |v_n(t,x)| <= M,
  ||D_x v_n(t,x)||_op <= M,
  ||D_x U(t,x)||_op <= M.

These pointwise derivative bounds use the operator norm of the spatial
differential (the source's fderiv). Integrated gradient-square expressions
use the sum of squared component derivatives. The constants below retain
the source's distinction between these two norms.

The cutoff-complement Sobolev estimate supplies K>=1, independent of n,
such that

  ||r_n(t)||_2^2 + ||grad r_n(t)||_2^2 <= 12 K^2/N^2.

Separately retain a finite projected-dissipation bound K_D satisfying

  ||grad v_n(t)||_2^2 <= K_D.

K_D, K and M are distinct constants. Their existence follows from the
actual smooth front; none is supplied as a new root premise.

INT06 -- RESIDUAL AND SIGNED ERROR ESTIMATE

The elementary physical transport estimate, with the established vector
normalizations, gives

  ||Rres_n||_2^2
    <= 6 M^2 (||r_n||_2^2+||grad r_n||_2^2)
    <= 72 M^2 K^2/N^2.

Set
  D_n := ||grad w_n||_2^2 >= 0,
  Zerr_n := ||A w_n||_2^2.

Differentiate the finite weighted coefficient sum defining D_n. Orthogonal
cutoff/Leray projection disappears when paired with A w_n. Thus

  D_n' + 2 nu Zerr_n
    = -2 <B(w_n,w_n),A w_n>
      -2 <B(v_n,w_n)+B(w_n,v_n),A w_n>
      +2 <Rres_n,A w_n>.

The first signed term equals twice the integral of convection(w_n) against
Delta w_n. Apply the existing arbitrary-field nonlinear absorption estimate,
which requires a smooth mean-zero field, not an unforced solution. Bound the
mixed terms using M and mean-zero Poincare; apply Young inequalities with
positive viscosity fractions to absorb the Laplacian-square terms. The
accepted native cross estimate has a universal C0>0 and yields

  D_n' <= (C0/nu^3) D_n^3 + (24 M^2/nu) D_n
           +(6/nu)||Rres_n||_2^2.

INT08 -- CLOSED-SLAB CONTINUITY AND INTERIOR COMPARISON

Every canonical coefficient is continuous on [0,T]. Every projected
reference coefficient is continuous there because T<S. Their difference
and its finite weighted norm-square sum are therefore continuous. This
supplies ContinuousOn D_n [0,T] independently of interior differentiation.

For an index n satisfying
  2 epsilon_n exp((2C+1)T) <= 1,
define the positive comparison function
  F_n(t) := 2 epsilon_n exp((2C+1)t).

Then F_n(0)>D_n(0), 2 epsilon_n<=F_n(t)<=1 on [0,T], and
  F_n'=(2C+1)F_n.
At a possible boundary contact D_n=F_n in the interior, D_n^3<=D_n, hence

  D_n' <= 2C F_n + epsilon_n
        < (2C+1)F_n = F_n'.

The scalar boundary comparison prevents crossing. Continuity near zero
provides a positive interior starting time; continuity at T gives the
terminal bound. No derivative at either endpoint is required. Consequently

  D_n(t) <= F_n(t) <= 1 for every t in [0,T].

Because epsilon_n->0, the smallness test holds eventually in n. Therefore
  eventually n, forall t in [0,T], D_n(t)<=1.
