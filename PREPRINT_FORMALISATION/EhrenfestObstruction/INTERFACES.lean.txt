3. CONCRETE DATA DEFINITIONS

These definitions are Lean-shaped schemas using the source-reviewed names
from SingularClosure. They are not claimed to elaborate unchanged.

  abbrev SmoothDatum := {a : SingularClosure.Field //
    SingularClosure.SmoothSigmaZero a}

  noncomputable def canonicalFamily
      (nu : Real) (hnu : 0 < nu) (a : SmoothDatum) (n : Nat) :
      SingularClosure.GalerkinSolution nu a.val (n + 1) :=
    SingularClosure.canonicalGalerkinSolution
      nu hnu a.val a.property (n + 1)

The logical index is n : Nat; the physical Fourier cutoff is ALWAYS n+1.
This avoids a zero-dimensional phase-space/lambda_max case. This cofinal
reindexing is equivalent to the eventual-positive-cutoff frozen statement.
One a, hnu, eStar, gamma and threshold family are fixed before quantifying n.

  def halfEnstrophy (N : Nat) (c : SingularClosure.FourierCoeff) : Real :=
    SingularClosure.coefficientDissipation N c / 2

  def reciprocalValue (eStar : Real) (N : Nat)
      (c : SingularClosure.FourierCoeff) : Real :=
    (1 + halfEnstrophy N c / eStar)⁻¹

  def reciprocalDrift (nu eStar : Real) (N : Nat)
      (c : SingularClosure.FourierCoeff) : Real :=
    (nu * SingularClosure.coefficientLaplacianSquare N c +
      SingularClosure.coefficientEnstrophyNonlinearPower N c) /
    (eStar * (1 + halfEnstrophy N c / eStar)^2)

SIGN CHECK: the existing D' is -2 nu Z - 2 P, where
P=coefficientEnstrophyNonlinearPower. Thus e'= -nu Z-P=W-nu Z with W=-P,
and reciprocalValue'=(nu Z+P)/(eStar(1+e/eStar)^2). A caloric shear has
P=0, so the reciprocal drift is nonnegative, as required physically.

  def canonicalEnstrophy (nu : Real) (hnu : 0 < nu)
      (a : SmoothDatum) (n : Nat) (t : Real) : Real :=
    halfEnstrophy (n + 1) ((canonicalFamily nu hnu a n).coeff t)

  def canonicalReciprocal (nu : Real) (hnu : 0 < nu)
      (a : SmoothDatum) (eStar : Real) (n : Nat) (t : Real) : Real :=
    reciprocalValue eStar (n + 1) ((canonicalFamily nu hnu a n).coeff t)

  def canonicalDrift (nu : Real) (hnu : 0 < nu)
      (a : SmoothDatum) (eStar : Real) (n : Nat) (t : Real) : Real :=
    reciprocalDrift nu eStar (n + 1) ((canonicalFamily nu hnu a n).coeff t)

  def PreHit (e : Real -> Real) (R T t : Real) : Prop :=
    0 <= t /\ t < T /\ forall s, 0 <= s -> s <= t -> e s < R

PreHit uses only real times and elementary inequalities. It avoids defining
an ENNReal infimum, and it retains the important restriction to [0,1/gamma).
It is equivalent to the frozen first-hit guard by continuity; that equivalence
is a theorem, not a new assumption. It does not presuppose that a hit exists.

  def StoppedForDatum (nu : Real) (hnu : 0 < nu) (a : SmoothDatum)
      (eStar gamma : Real) (R : Nat -> Real) : Prop :=
    0 < eStar /\ 0 < gamma /\
    (forall n, 0 < R n) /\
    Filter.Tendsto R Filter.atTop Filter.atTop /\
    exists n0 : Nat, forall n, n0 <= n -> forall t,
      PreHit (canonicalEnstrophy nu hnu a n) (R n) (1 / gamma) t ->
      canonicalDrift nu hnu a eStar n t <= -gamma

  def StoppedCommutatorBound (nu : Real) : Prop :=
    exists hnu : 0 < nu, exists a : SmoothDatum,
      exists eStar gamma : Real, exists R : Nat -> Real,
        StoppedForDatum nu hnu a eStar gamma R

This public predicate has only nu as an argument, preserving the frozen
root shape. The positivity proof hnu is existentially bound to make the
canonical function application explicit. Lean proof irrelevance reconciles
it with any external hnu supplied to the theorem. Do not remove nu from the
family or silently apply a theorem at a different viscosity.

  def NSE_B (nu : Real) : Prop :=
    forall a : SingularClosure.Field,
      SingularClosure.SmoothSigmaZero a ->
      exists U : SingularClosure.Velocity,
      exists P : SingularClosure.Pressure,
        SingularClosure.GlobalSmoothNSE nu a U P

The root quantifies the actual project physical solution predicate, not a
replacement definition of regularity through the stopped condition.

DATA/PROP CAUTION
Do not make a Prop-valued structure with data-bearing projections a : Field,
gamma : Real, or R : Nat -> Real and then try to use those projections to
define canonical trajectories. Use explicit existential binders as above.
Alternatively make a Type-valued parameter record and put all its laws in
a separate Prop; the existential root may quantify that record. Extract
witnesses from StoppedCommutatorBound only inside Prop-valued proofs. The
canonical family itself takes explicit data and positivity/smoothness proofs.

5. CLOSED-SLAB AND ENDPOINT SEMANTICS

An InitialClassicalFront with endpoint exactly T generally supplies an open
time front [0,T), not regularity through its endpoint. It cannot be used as
the hypothesis of a uniform estimate on [0,T] without an extra argument.
The safe already-typed adapter is signature (4) with T<S. A global smooth
solution supplies S=T+1 immediately, so the literal frozen root is unchanged.

The stronger mathematical E09 statement remains valid for an actual smooth
closed-slab solution: the proof needs continuous H4 control and the projected
NSE equation through the open interior, with its initial trace, not an assumed
Galerkin bound. Preserve that direct proof in the B-tier text. For formal
acceptance of its stronger interface, either:
  - define a concrete ClosedSmoothNSESlab using actual fields, PDE, periodicity,
    initial trace and joint smoothness/continuous Sobolev traces on [0,T], and
    derive the required compact H4 bound; or
  - derive the relevant continuous Sobolev-slab interface from those actual
    closed-slab hypotheses before applying the H2 error estimate.
Do not define ClosedSmoothNSESlab to include Galerkin convergence or uniform
Galerkin enstrophy. Do not mark the stronger closed-slab declaration accepted
merely because the easier T<S front wrapper has passed.

For the data-specific conclusion that maximal lifetime is <=1/gamma, the
strict-front wrapper is already sufficient: if Tmax>1/gamma, choose a finite
S strictly between them and apply (4). The frozen no-global-solution root
therefore loses no strength by implementing that wrapper first.

6. DIRECT RESOLVENT CONSTRUCTION IN PLACE OF A GENERAL STONE PORT

The proposed alternative is correct. Once the explicit strongly continuous
unitary group U(t) is constructed, define its strong derivative generator L
on the actual domain of vectors for which lim_(h->0)(U(h)f-f)/h exists.
The domain is dense because it contains C_c^infty. Differentiating unitarity
shows L is skew-symmetric on this domain.

Define bounded Bochner integrals
  R_+ f = integral_0^infinity exp(-t) U(t)f dt,
  R_- f = integral_0^infinity exp(-t) U(-t)f dt.
They converge because ||exp(-t)U(+/-t)f||<=exp(-t)||f||, and have operator
norm at most one. The group law and a change of time variable give
  L R_+ f=R_+ f-f,     (I-L)R_+=I,
  L R_- f=f-R_- f,     (I+L)R_-=I.
These derivatives use continuity of U at zero and the integrable exponential
tail; they prove R_+/- f belongs to the actual generator domain.

A densely defined skew-symmetric operator with both I-L and I+L surjective
is skew-adjoint. Explicitly L is contained in -L*. For y in D(L*), choose
x in D(L) satisfying (I-L)x=(I+L*)y. Then (I+L*)(y-x)=0. But this kernel is
the orthogonal complement of range(I+L), which is zero by surjectivity.
Thus y=x is in D(L), and L*=-L. In particular L is closed.

Set H=i*hbar*L; then H is self-adjoint and U has strong derivative generator
(-i/hbar)H. The time-convolution graph-core proof from E04 identifies closure
of the explicit H0 with this H. Therefore no assumed general Stone theorem
or self-adjointness certificate is needed as an analytic premise.

Formal implementation still needs actual Bochner-integral, adjoint-domain,
surjectivity and generator-domain arguments. An unchecked structure recording
those conclusions is not a proof. If U=exp(-itH/hbar) is used as literal
functional-calculus notation, the associated functional-calculus construction
or generator uniqueness theorem must also be supplied. The statement that
U is the strongly continuous unitary group generated by H is already exact
and sufficient for the Heisenberg/Ehrenfest identities.

7. ANTI-CIRCULARITY CHECKS

- StoppedCommutatorBound contains only one fixed datum, actual canonical
  Galerkin trajectories, explicit reciprocal drift, positive constants,
  divergent thresholds and the pre-hit rate inequality. It contains no
  singularity, no failure of continuation, no Galerkin instability, and no
  desired conclusion as a field.
- The drift is the stated rational coefficient expression, not `deriv v`
  with an unrelated differentiability certificate or a chosen arbitrary rate.
  Exact derivative identification is proved separately.
- Uniform initial enstrophy is reused only at time zero. Uniform-in-time
  Galerkin bounds in the contradiction are proved from the hypothetical
  actual smooth solution by the H2 error bootstrap.
- E09 must not consume `forall N, integral H2^2 <= C` or a certificate of
  Galerkin convergence. Those are the very analytic control being derived.
- Every n uses cutoff n+1 and the same actual viscosity and datum.
- The stopped horizon is min(first-hit,1/gamma), represented by PreHit.
  Do not strengthen it to a forever-negative commutator rate.
- The phase-space H is distinct from any state-dependent velocity-space
  operator G=-i*hbar*C(u). No uncertainty-product identity for G may silently
  be substituted for the phase-space generator H.
- Formal success of the conditional implication does not prove that the
  existential stopped premise has a witness, and does not refute NSE-B.
- Completing the dynamics branch does not certify the separate operator
  construction; every acceptance marker must retain its literal scope.
