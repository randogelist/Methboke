1. LEAF SCALAR COMPARISON -- SlabDescent.lean

  theorem terminal_le_of_rate_le
      (v rate : Real -> Real) (T gamma : Real)
      (hT : 0 < T)
      (hcont : ContinuousOn v (Icc 0 T))
      (hderiv : forall t in Ioo 0 T, HasDerivAt v (rate t) t)
      (hrate : forall t in Ioo 0 T, rate t <= -gamma) :

The generic lemma does not need gamma>0. It uses an explicit derivative rate
and continuity on the closed slab; no endpoint derivatives are assumed.

7. DERIVED INTERNAL H1 ERROR INTERFACE

The actual finite error satisfies D_n(0)=0 and, on (0,T),
  D_n' <= C*(D_n+D_n^3)+A0/(n+1)^2,
where C=C0/nu^3+24*M^2/nu+1 and A0=432*M^2*K^2/nu.

Source: initial_front_canonical_error_differential_inequality in
CanonicalErrorInequality.lean. Continuity of coefficient differences and their
finite weighted norm squares is proved in EventualEnstrophyBound.lean.

The interior comparison theorem
  guarded_cubic_small_forcing_bound_interior
in SmallForcingBootstrap.lean uses the fence
  F_n(t)=2*epsilon_n*exp((2*C+1)*t), epsilon_n=A0/(n+1)^2.
For 2*epsilon_n*exp((2*C+1)*T)<=1, it proves D_n<=F_n<=1 on [0,T].
This works with interior derivatives only. The eventual form is
  eventually_guarded_cubic_unit_bound_interior.
Reconstruction uses the separately derived projected dissipation bound to
obtain e_n<=1+K_D. Every bound is internal to the actual-front proof.
