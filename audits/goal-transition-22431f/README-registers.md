# Pre-transition register archive

These five byte-identical files preserve the repository registers at
`22431f032c868b8de1526767d7d32a2639f6a9ee`, before the user selected the
conditional `EHRENFEST_OBSTRUCTION` root as the project goal.

They are historical evidence, not current operating instructions. Their old
"current" goals, pending statuses and runner handoff rules are superseded by
the corresponding documents at the repository root. No historical theorem,
source identity, failed attempt or acceptance record is removed.

[registers-manifest.json](registers-manifest.json) records byte counts and
SHA256 identities. The goal change changes neither the mathematical statement
of WFB nor its accepted finite-budget scope.
