PURPOSE
=======

This file turns the adopted ten-step QFA route into a dependency-ordered Lean
assembly DAG. Existing declarations, proposed adapters, construction providers,
and final consumers are separated so later work can proceed package by package
without changing the mathematical target.

The final root must prove the existing native propositions:

  MethbokeAddon.QuasiFeffermanA.PhysicalRoot.ClosedQuasiFeffermanA
  MethbokeAddon.QuasiFeffermanA.PhysicalRoot.QuasiFeffermanA

with the unchanged physical cutoff

  tau_A(a,nu) = 8 * ||a||_2^4 / (27*pi^4*nu^5).
