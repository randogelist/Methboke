1. ACTUAL REAL AND COMPLEX CARRIERS

Use the already admitted componentwise real linear isometry c:L_R->L_C.

Thus f belongs to the actual range of c iff C_L f=f. This implication

2. CONJUGATE-REFLECTION AND FOURIER

The Euclidean linear isometry x->-x preserves volume, so pullback defines
an actual complex linear isometry D_L on L2, with D_L f(x)=f(-x) a.e.
Define J=C_L D_L as a bounded real linear map. Hence
Jf(x)=conjugate(f(-x)) a.e.

For an arbitrary complex vector-valued Schwartz function phi, not only a
real one, the defining Fourier integral and conjugation of the character
give

  F(C phi)(xi) = C(F phi(-xi)).

Conjugation commutes with the Bochner integral as a real linear isometry;
the character identity is conj(exp(2*pi*i*s))=exp(-2*pi*i*s). Therefore
the identity holds with the actual Schwartz Fourier map. Compatibility
of Schwartz-to-L2 with F and the a.e. representative formulas identify
both L2 sides on Schwartz inputs. Schwartz functions are dense in L_C;
both sides are continuous. Consequently

  F(C_L f)=J(Ff)                     for every f in L_C.

Injectivity of the L2 Fourier isometry now gives

  C_L f=f  <=>  J(Ff)=Ff,
  f in range(c) <=> J(Ff)=Ff.

Applying the same criterion to F^(-1)f also gives the literal frequency-side
range characterization: exists real u with F(cu)=f iff Jf=f.

This direct complex-Schwartz density proof supplies the full transport
identity without a separate real/imaginary decomposition argument.
